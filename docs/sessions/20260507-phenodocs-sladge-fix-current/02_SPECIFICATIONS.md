# Specifications

## Scope

- Add Sladge badge disclosure to `README.md`.
- Add session docs for current-branch governance evidence.
- Do not modify workflows, docs content, package config, or source code.

## Acceptance Criteria

- `README.md` contains the Sladge badge.
- Session docs identify why stale evidence was replaced.
- Validation covers diff hygiene, badge presence, and available repo-native
  checks.
