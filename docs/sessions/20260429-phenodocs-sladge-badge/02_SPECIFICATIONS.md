# Specifications

## Acceptance Criteria

- README badge block includes the Sladge badge.
- Badge links to `https://sladge.net`.
- No docs federation code, build config, changelog, ADR, SOTA, or specs are modified.
- Session docs record the isolated-worktree reason.

## Out Of Scope

- VitePress federation changes.
- `.llms.txt` generation behavior.
- MCP tool implementation.
- Runtime validation beyond docs-only checks.
